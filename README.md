# 4行日記 (DailyDiary)

毎日決まった時刻にポップアップで「4行日記（事実・発見・教訓・宣言）」の入力を促す、
Windows のシステムトレイ常駐アプリです。Python + PySide6 製。

## 起動方法

- 通常起動（コンソール無しで常駐）: `run.bat` をダブルクリック
- デバッグ起動（ログをコンソール表示）: `run_debug.bat`

いずれもホーム直下の仮想環境 `%USERPROFILE%\ddvenv` の Python を使います。

## 使い方

1. 起動するとシステムトレイにアイコンが常駐します。
2. トレイアイコンを右クリック →
   - **今日を書く**: 4行日記の入力画面を開く
   - **設定**: リマインダー時刻・ポップアップ強度・自動起動などを設定
   - **同期する**: Confluence 同期（Phase 3 で実装予定）
   - **終了**: アプリを終了
3. 設定した時刻になると入力画面が自動で開きます（その日まだ未入力の場合）。

## 保存先（Portable）

実行フォルダを基準に保存します。

```
4行日記/
├─ main.py / app/ ...
├─ config.json        設定
├─ data/              日記本体（diary_YYYY.jsonl）
└─ logs/              app.log
```

## 開発フェーズ

- **Phase 1（実装済み）**: トレイ常駐 / 定時リマインダー / 4行入力 / JSONL保存 / 設定 / 自動起動
- Phase 2: Force モード強化・スヌーズ運用・Portable 整備
- Phase 3: Confluence 同期（接続テスト・ページ作成・リトライ）
- Phase 4: PyInstaller での .exe 配布・初回設定ウィザード・API Token 安全保存
